# License Options

Linux demos read `FR_LICENSE_KEY` for Face Recognition, `FL_LICENSE_KEY` for Face Liveness, and `LICENSE_KEY` for both document demos. Each supports an authorized root `license.txt` where supplied.

Use only the authorization issued with the matching package. Release materials define scope, initialization behavior, and recovery for validation errors.

To request a package-specific license, see [Contact & Support](contact-and-support.md).

## <i class="fa-mobile-screen">:mobile-screen:</i> Android application IDs

Check [Demos & Downloads](demos-and-downloads.md) for the Android edition you’re using, then follow its licensing guide. The entitlement needs to match the app’s application ID.
