# Release Notes

The shipped demo HTTP interface is version `1.0.0` for each FastAPI service. Face Recognition, Face Liveness, and ID Recognition use port `8000`; ID Document Liveness uses `9000`.

Each bundle ships a local Streamlit interface, a FastAPI service, and a Python adapter for its matching SDK. Engine versions are separate from the demo interface version. Use vendor release materials for dated changes and migrations.

## <i class="fa-box">:box:</i> Check the version you installed

Check the version supplied with your package before comparing behavior across releases. Use [Demos & Downloads](demos-and-downloads.md) to find the matching setup guide.
