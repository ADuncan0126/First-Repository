# Performance Overview

## ID Document Liveness Detection performance overview

Use approved genuine and authorized presentation-attack samples. Keep documents and acquisition sessions separate between development and test sets.

Measure attack and bona-fide error rates at the selected threshold. Track recapture, worker failure, and cold/warm latency separately. Record resize configuration. This is an integrity signal, not a universal document-authenticity decision.

## <i class="fa-chart-line">:chart-line:</i> Record the test configuration

Report how many inputs produced a usable result and how many required recapture or produced a technical error.
