# Quickstart

## ID Document Recognition quickstart

1. Install and activate the platform package.
2. Initialize document capture using release-approved configuration.
3. Capture a complete, readable document image.
4. Classify the document and validate extracted fields.

Expect a document result only from a complete, readable capture. Route unreadable images to guided recapture. Field names and API signatures require release materials.
