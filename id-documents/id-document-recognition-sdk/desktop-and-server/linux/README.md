# Linux

## **ID Document Recognition on Linux**

Extract text from identify document images.

Review results in Streamlit or submit an image through FastAPI

### **SDK  capabilities**

<table><thead><tr><th width="216">Feature</th><th>Specification</th></tr></thead><tbody><tr><td><strong>Document image input</strong></td><td>Submit an identify document image</td></tr><tr><td><strong>Text recogniton (OCR)</strong></td><td>Extract readable text from the document</td></tr><tr><td><strong>Interactive demo</strong></td><td>Review recognition results in Streamlit</td></tr><tr><td><strong>HTTP API</strong></td><td>Send document images through FastAPI</td></tr><tr><td><strong>SDK activation</strong></td><td>Configure a license before running recognition</td></tr></tbody></table>

### **Reference performance**

{% hint style="info" %}
Document processing time depends on image resolution, whether you process one or both sides of the document, and the hardware running the SDK.
{% endhint %}
