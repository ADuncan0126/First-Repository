# Linux

## **Face Recognition SDK for Linux**

Detect faces and extract biometric templates in C++ and Python applications.

Install the SDK, run the Linux demo, and validate API calls before integration.



### **SDK capabilities**

<table data-search="false"><thead><tr><th width="273">Capability</th><th>Specification</th></tr></thead><tbody><tr><td>Supported languages</td><td>C++ and Python</td></tr><tr><td>Face detection</td><td>Single face by default. Multi-face detection can be detected.</td></tr><tr><td>Face template extraction</td><td>512 float32 values, little-endian (2,048 bytes per template)</td></tr><tr><td>1:N face identification</td><td>Can be implemented as an extension to search enrolled templates.</td></tr><tr><td>Face liveness detections</td><td>Available through the separate Face Liveness Detection SDK</td></tr><tr><td>Facial attribute analysis</td><td>Unsupported</td></tr></tbody></table>
