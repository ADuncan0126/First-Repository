# Choose an SDK

Choose **Face Recognition** for identification or face matching. Choose **Face Liveness Detection** to assess presentation-attack resistance.

Choose **ID Document Recognition** to extract and validate document data. Choose **ID Document Liveness Detection** to assess document capture authenticity.

Validate the task against your SDK release materials before implementation.

## <i class="fa-compass">:compass:</i> Go to the SDK guide

- [Face Recognition](../face-biometrics/face-recognition-sdk/README.md) to compare two face images.
- [Face Liveness Detection](../face-biometrics/face-liveness-detection-sdk/README.md) to assess liveness from one face image.
- [ID Document Recognition](../id-documents/id-document-recognition-sdk/README.md) to read supported fields from an identity document.
- [ID Document Liveness Detection](../id-documents/id-document-liveness-detection-sdk/README.md) to evaluate the liveness of a document image.
