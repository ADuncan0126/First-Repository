# About Truverion

## Overview

Truverion provides biometric SDKs for face recognition, face liveness, and identity documents. Build identity workflows in your chosen application environment.

### Start here

Review [platform-compatibility.md](get-started/platform-compatibility.md "mention") before selecting a runtime. Run an authorized local package from [demos-and-downloads.md](resources-and-support/demos-and-downloads.md "mention").

Use the release materials supplied with the SDK package as the source of truth. They define supported versions, downloads, API signatures, and license terms.
