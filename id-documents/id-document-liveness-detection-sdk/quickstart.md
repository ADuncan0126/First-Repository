# Quickstart

## ID Document Liveness Detection quickstart

1. Install and activate the Linux package.
2. Initialize the liveness flow using release-approved settings.
3. Capture the document with complete edges and sufficient detail.
4. Apply your policy to the resulting assessment.

Expect an assessment, recapture, policy failure, or SDK error. Keep capture failure, policy failure, and SDK error distinct. Exact method signatures require release materials.
