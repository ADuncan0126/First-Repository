# Sample Application

Run the iOS Face Recognition sample on a physical device. Validate authorization, preview orientation, detection, and known comparison before integration.

See [Sample Application](../../desktop-and-server/linux/sample-application.md) for local demo guidance.

## <i class="fa-list-check">:list-check:</i> Run a device check

1. Complete [Installation](installation.md) and [Licensing & Activation](licensing-and-activation.md).
2. Run the matching sample on a supported device. Grant camera permission if prompted.
3. Use an approved fixture to compare two face images. Expect a similarity score and comparison outcome.
4. Test a poor-quality capture and denied camera permission so the app gives users a clear next step.
