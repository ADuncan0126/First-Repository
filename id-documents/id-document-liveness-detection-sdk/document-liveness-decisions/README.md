# Document Liveness Decisions

## Document Liveness Decisions

Treat `genuine` and `spoof` as document-integrity signals. If any integrity score is below the selected threshold, the service returns `spoof`. Scores are not probabilities.

Request recapture for bad framing or image quality. Retry only a transient worker or runtime failure. Send unresolved outcomes to manual review. Do not use this signal alone as a document-authenticity determination.
