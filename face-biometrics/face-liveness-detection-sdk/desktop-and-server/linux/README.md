# Linux

## **Face Liveness Detection SDK for Linux**

Evaluate face liveness from a single image.

Run the Streamlit demo or submit an Image through FastAPI.



### **SDK capabilities**

<table data-search="false"><thead><tr><th width="273">Feature</th><th>Specification</th></tr></thead><tbody><tr><td>Face detection</td><td>Face bounding box when available</td></tr><tr><td>Liveness result</td><td>Real, or SPOOF with a liveness score</td></tr><tr><td>Head pose</td><td>Pitch, yaw, and roll when available</td></tr><tr><td>Default threshold</td><td>0.5, configurable</td></tr><tr><td>Demo interfaces</td><td>Streamlit and FastAPI</td></tr><tr><td>API input</td><td>Image upload or Base64 JSON</td></tr></tbody></table>

### **Reference performance**

{% hint style="info" %}
