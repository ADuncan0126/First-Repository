# Installation

Add the Face Recognition iOS package from the matching release. Configure required capabilities and bundled assets as specified in release materials. Package instructions are release-specific.

## <i class="fa-list-check">:list-check:</i> Configure the Xcode target

1. Confirm the release’s minimum iOS version, device architectures, and integration method.
2. Add the SDK and any required assets using the release instructions. Select your app target and configure signing.
3. If you use live capture, add a camera usage description and request permission before opening the camera.
4. Build on a supported physical device and complete [Licensing & Activation](licensing-and-activation.md).
