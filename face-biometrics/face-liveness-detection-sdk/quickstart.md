# Quickstart

## Quickstart

1. Install and activate the target package.
2. Initialize the liveness session using release-approved settings.
3. Capture according to your user guidance.
4. Submit the result to your liveness policy.

Expect an assessment, a guided retry, or a technical error. Keep retry, failure, and technical-error states separate. Exact API calls require release materials.
