# Licensing & Activation

Configure the iOS Face Liveness entitlement before initialization. Do not expose credentials in the application or logs.

Activation flow requires release materials.

## <i class="fa-list-check">:list-check:</i> Prepare the licensed app

Copy the app target’s bundle identifier from Xcode when requesting an entitlement. Check the release instructions for the license format and initialization sequence. If activation fails, confirm the app identifier and package version, then contact [Truverion support](../../../../resources-and-support/contact-and-support.md) with a redacted diagnostic.
