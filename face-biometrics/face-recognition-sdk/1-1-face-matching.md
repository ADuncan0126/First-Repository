# 1:1 Face Matching

## 1:1 Face Matching

The demo exposes only 1:1 comparison. Submit two images of the same person and two images of different people using approved fixtures. Select a threshold for your policy, then retain the threshold with every decision.

Compare `similarity` with the returned `threshold` when supplied. Handle no-face or unusable-image outcomes as recapture requests. Do not log or expose feature JSON. Any 1:N workflow is application-designed and is not exposed by this demo.

Use the matching release documentation and `engine/header.py` for native method signatures.
