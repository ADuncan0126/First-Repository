# Platform Compatibility

## Platform Compatibility

| Package target          | Documented Linux demo | Other integration pages                                     |
| ----------------------- | --------------------- | ----------------------------------------------------------- |
| Face Recognition        | Ubuntu 22.04          | Android and iOS availability requires package confirmation. |
| Face Liveness           | Ubuntu 22.04          | Android and iOS availability requires package confirmation. |
| ID Document Recognition | Ubuntu 22.04          | Android and iOS availability requires package confirmation. |
| ID Document Liveness    | Ubuntu 22.04          | Linux is the documented demo target.                        |

Use native assets matching the package architecture and operating-system release. Do not mix engine builds or substitute incompatible OpenSSL libraries. The integration pages describe planning guidance, not release availability.
