# Sample Application

Run **ID Scan** on a physical Android phone.

Follow [Installation](installation.md) and [Licensing & Activation](licensing-and-activation.md), then launch the app and check the SDK status.

1. Open the camera and grant camera permission, or choose a document photo from the gallery.
2. For camera capture, keep the whole document in view and avoid glare or blur. For gallery input, use a complete, readable image.
3. Review the recognized document information in the result screen. Check the portrait view when the engine returns a portrait. Try a clearer capture if recognition returns an unknown document or incomplete fields.

The project ZIP contains the demo source. Obtain the licensed `idsdk.aar` and the license for `tech.truverion.id.rec` through your authorized package channel.
